# Where do the gender labels come from?

Either the raw dataset has them all, like in US patents (`uspt`), or partially like in movies (`imdb`) based on actor/actoress but missing for other cast'ncrew like director, or no label at all like in computer science papers (`dblp`). Here are the steps we performed to obtain the missing gender labels.

---
### I: Obtaining Gender Labels for Experts

> Using [`main.py`](https://github.com/fani-lab/Adila/blob/main/src/genderize/main.py),

1- We collect `unique` experts' `firstname` in `uniqueNames.csv` 

2- We then call an api in batches to label the `firstname`'s gender using either [`genderize`](https://api.genderize.io) or [`gender-api`](https://gender-api.com)

3- We populate the gender labels in `uniqueNames_populated.csv`

>> Refer to [`./toy/main.py`](./toy/main.py) for a `toy` run for a few experts in [`input.csv`](./toy/input.csv) and the results in [`output.csv`](./toy/output.csv).

> Using [`c2g.py`](c2g.py) (candidate-to-gender),

4- Finally, we re-store the gender labels based on the `id_name` that uniquely represent an expert candidate in a dictionary `{id_name: (gender, accuracy)}` in the `c2g.pkl`. These files are already available on Hugging Face for `dblp`, `uspt`, and `imdb` datasets:

>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/dblp/dblp.v12.json/c2g.pkl`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/dblp/dblp.v12.json/c2g.pkl)
>> 
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/uspt/patent.tsv/c2g.pkl`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/uspt/patent.tsv/c2g.pkl)
>> 
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/imdb/title.basics.tsv/c2g.pkl`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/imdb/title.basics.tsv/c2g.pkl).

>> The `id_name` key is important since it also maps an expert to its column index in `c2i` (candidate-to-index) in `indexes.pkl` file, generated after preprocessing a dataset into `teamsvecs.pkl` in OpeNTF's dataset preprocessing step. So, we can map the gender label to the column index, also generate the `females.csv` for the column indices of female experts. 

---

### II: Store Labels for Female Experts Only

> Using [`i2g.py`](i2g.py),

1- We generate `females.csv`, which contains the column indices of female experts for a given dataset. Since females are minority group in datasets, the choice of only storing the column index of females is more space efficient (vs. indexes of males or indexes for both). 

2- We also save a pickled dictionary `i2g.pkl` that maps each column index into `(col_index: (isfemale, acc))`. 

The `i2g.pkl` and `females.csv` files for `dblp`, `uspt`, and `imdb` datasets are available on Hugging Face:

>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/dblp/dblp.v12.json/i2g.pkl`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/dblp/dblp.v12.json/i2g.pkl)
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/dblp/dblp.v12.json/females.csv`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/dblp/dblp.v12.json/females.csv)
>> 
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/uspt/patent.tsv/i2g.pkl`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/uspt/patent.tsv/i2g.pkl)
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/uspt/patent.tsv/females.csv`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/uspt/patent.tsv/females.csv)
>> 
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/imdb/title.basics.tsv/i2g.pkl`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/imdb/title.basics.tsv/i2g.pkl).
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/imdb/title.basics.tsv/females.csv`](https://huggingface.co/datasets/fani-lab/OpeNTF/blob/main/output/imdb/title.basics.tsv/females.csv).

### II: re-Store Labels for Female Experts Only in a Filtered Dataset

When a dataset is filtered, like removing teams with single or less than a threshold number of expert, or removing experts with fewer than a threshold number of teams, as indicated in [`OpeNTF`](https://github.com/fani-lab/OpeNTF)'s data preprocessing step [`https://github.com/fani-lab/OpeNTF/blob/main/src/__config__.yaml#L36`](https://github.com/fani-lab/OpeNTF/blob/main/src/__config__.yaml#L36), the ordering and column indices of experts may change. As a result, the original gender mapping no longer aligns with the filtered dataset. Therefore, the `females.csv` file for a filtered dataset should be re-generated by running `i2g.py`'s function `generate_i2g_and_female_csv`, using the following inputs:

![#3282F6](https://placehold.co/15x15/3282F6/3282F6.png) **Inputs:**

- `c2g.pkl`: candidate-to-gender mapping for the **`full`** dataset, available on Hugging Face as linked above.

- `indexes.pkl`: the index pickle file for the **`filtered`** dataset, generated in the corresponding filtering output directory (e.g., `/OpeNTF/output/dblp/dblp.v12.json`**`.mt10.ts2`**).

![#3282F6](https://placehold.co/15x15/3282F6/3282F6.png) **Output:**

- `females.csv`: contains the column indices of female experts in the filtered dataset.

- `i2g.pkl`: contains the index-to-gender for both male and female experts in the filtered dataset.

The `i2g.pkl` and `females.csv` files for **`filtered`** datasets of `min_team_size = 2` and `min_nteam = 10` for `dblp`, `uspt`, and `imdb` datasets are available on Hugging Face:

>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/tree/main/output/dblp/dblp.v12.json.mt10.ts2`](https://huggingface.co/datasets/fani-lab/OpeNTF/tree/main/output/dblp/dblp.v12.json.mt10.ts2)
>> 
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/tree/main/output/uspt/patent.tsv.mt10.ts2`](https://huggingface.co/datasets/fani-lab/OpeNTF/tree/main/output/uspt/patent.tsv.mt10.ts2)
>> 
>> [`https://huggingface.co/datasets/fani-lab/OpeNTF/tree/main/output/imdb/title.basics.tsv.mt10.ts2`](https://huggingface.co/datasets/fani-lab/OpeNTF/tree/main/output/imdb/title.basics.tsv.mt10.ts2).

---

**Notes:**

- A separate `females.csv` file must be generated for each filtered dataset.
- Ensure that `c2g.pkl` corresponds to the same base dataset as the filtered dataset.
